How to Use

1. Registration

Create an account with your email and password. Upload a profile photo to get started.

2. Profile Setup

Complete your profile with interests, photos, and personal information.

3. Find Matches

Browse other members using filters for age, location, and interests.

4. Connect

Like profiles and send messages to your matches. The application shows you when other users are online for timely interactions.

5. Stay Engaged

Receive instant notifications when your matches are active or when you receive new messages. Engage in real-time conversations.

Key Features

  • Secure Authentication with JWT & Role-based Authorization
  • Real-time Private Messaging with SignalR
  • Cloud-based Photo Management using Cloudinary
  • Advanced Member Filtering & Matching System
  • Interactive User Profiles with Multiple Photos
  • Real-time Presence Tracking System for User Engagement
  • Real-time Notifications & Activity Tracking
  • Like System with Match Notifications
